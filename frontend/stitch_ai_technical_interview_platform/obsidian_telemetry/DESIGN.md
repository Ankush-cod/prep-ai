## Brand & Style

The design system establishes a high-performance, developer-first environment tailored for technical rigor and engineering interview readiness. It synthesizes the visual discipline of Linear, the structural typographic precision of Vercel, and the focused density of modern IDEs. 

The aesthetic is anchored in an obsidian tonal architecture: pitch-black canvases, razor-sharp 1px boundary lines, and precise, purposeful luminescent accents. Visual noise is aggressively eliminated to preserve cognitive focus during complex algorithm evaluations and technical simulations. The emotional tone is authoritative, analytical, and frictionless. Interactive feedback mimics low-latency terminal workflows, treating code telemetry, data metrics, and technical rubrics as first-class citizens.

## Colors

The color system operates on an obsidian scale calibrated for deep-focus development environments, complemented by high-contrast functional signals.

### Surface Architecture
- **Canvas Base:** `#0B0C10` (Pure obsidian baseline canvas)
- **Surface Layer 1:** `#12141C` (Panels, code editors, split containers)
- **Surface Layer 2:** `#181B26` (Floating sheets, card tiers, active workspaces)
- **Surface Layer 3:** `#202433` (Elevated overlays, popovers, dropdown lists)
- **Subtle Technical Border:** `#262A38` (Structural 1px component borders)
- **Muted Border:** `#1D212C` (Internal dividers, column delimiters)

### Primary & Functional Accents
- **Primary Violet:** `#8B5CF6` (Core interactive triggers, cursor accents, active states)
- **Violet Glow / Hover:** `#A78BFA` (Hover highlights, luminous metric focus)
- **Deep Violet:** `#7C3AED` (Active press states, pressed button backgrounds)

### Engineering Branch Tracks
- **Computer Science & Engineering (CSE):** `#8B5CF6` (Electric Violet) paired with `#06B6D4` (Cyan) for dynamic logic paths.
- **Electronics & Communication (ECE):** `#10B981` (Emerald) and `#14B8A6` (Teal) for signal processing and embedded telemetry.
- **Electrical Engineering (EE):** `#F59E0B` (High-voltage Amber) for systems, circuit analysis, and state machines.
- **Mechanical Engineering (ME):** `#F43F5E` (Crimson) to `#FB7185` (Coral) for structural mechanics, kinematics, and thermodynamics.

### Semantic Status
- **Success:** `#10B981` (Test suite passed, optimal algorithmic complexity)
- **Warning:** `#F59E0B` (Time/memory threshold warnings, sub-optimal Big-O)
- **Critical / Error:** `#EF4444` (Runtime panic, compilation failure, memory leak)
- **Informational:** `#06B6D4` (Telemetry status, system ping, profiling metrics)

## Typography

The typographic hierarchy prioritizes micro-legibility and tabular alignment. Headings and interface labels utilize Geist, applying subtle negative tracking (`-0.01em` to `-0.03em`) across larger sizes to achieve high visual tension without sacrificing readability.

Code segments, metric outputs, memory consumption telemetry, and complexity notations rely on a clean monospaced stack (`JetBrains Mono`, `Geist Mono`, or standard monospaced fallbacks). Monospaced sizes feature tabular figures (`font-variant-numeric: tabular-nums`) by default to prevent layout shifts during real-time telemetry updates and code executions.

## Layout & Spacing

The layout model adapts a strict 12-column engineering grid for structural dashboard screens, transitioning to multi-pane split layouts for Monaco editor and technical interview workspaces.

- **Split-View Canvas:** Interactive interview sessions use fluid resizable horizontal and vertical panes. Left panes anchor problem parameters and branch rubrics; right panes hold the Monaco code execution buffer and telemetry console. Minimum pane width is pinned to `320px`.
- **Vertical Spacing Cadence:** Built on a disciplined 4px base module (`0.25rem`). Component paddings strictly use `space-xs` (4px), `space-sm` (8px), `space-md` (16px), and `space-lg` (24px).
- **Responsive Adaptations:**
  - **Desktop (≥1200px):** 12 columns, 24px gutters, fixed-rail navigation alongside fluid workspace panes.
  - **Tablet (768px - 1199px):** 8 columns, 16px gutters; side-by-side IDE windows collapse into switchable tabular panels (Spec / Code / Output).
  - **Mobile (<768px):** 4 columns, 16px margins; interface collapses into single-task viewports with bottom tab switches for code preview, interview prompts, and system feedback.

## Elevation & Depth

This design system eschews heavy blurred shadows in favor of precise physical borders and subtle background value shifts.

- **Level 0 (Canvas):** Pure `#0B0C10`. Flat, non-interactive ground.
- **Level 1 (Structural Paneling):** `#12141C` bounded by a 1px border of `#262A38`. Used for editor split-panes, sidebars, and persistent docked docks.
- **Level 2 (Cards & Active Widgets):** `#181B26` with a 1px border of `#262A38`. On hover, border color shifts to `#3B4155` with an internal top hairline glow (`inset 0 1px 0 0 rgba(255, 255, 255, 0.05)`).
- **Level 3 (Overlays, Modals, Menus):** `#202433` elevated by a direct shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.65)` enclosed in a 1px `#3E455B` boundary.
- **Active Focus Ring:** A crisp `0 0 0 1px #8B5CF6` accompanied by an ambient bloom `0 0 16px rgba(139, 92, 246, 0.25)`.

## Shapes

The geometric framework uses a precise 0.25rem (`roundedness: 1`) baseline radius, reinforcing a disciplined, developer-centric software feel.

- **Base Components (Inputs, Buttons, Badges):** `4px` (`0.25rem`). Sharp, deliberate corners that mimic technical terminal environments.
- **Panels & Containers:** `8px` (`0.5rem`, `rounded-lg`). Enclosing cards, code panel viewports, and modal windows.
- **Status Indicators & Avatars:** Fully rounded (`9999px`) circles strictly reserved for telemetry status beacons, live interview presence indicators, and user avatars.

## Components

### Buttons
- **Primary:** Background `#8B5CF6`, text `#FFFFFF`, border `1px solid transparent`. Hover shifts to `#7C3AED` with an subtle upward box-shadow highlight (`inset 0 1px 0 rgba(255,255,255,0.2)`).
- **Secondary:** Background `#181B26`, text `#E2E8F0`, border `1px solid #262A38`. Hover shifts background to `#202433` and border to `#3B4155`.
- **Ghost / Terminal:** Background `transparent`, text `#94A3B8`, border `1px solid transparent`. Hover gives `#12141C` background and `#F8FAFC` text.

### Telemetry Badges & Status Indicators
- **Structure:** Height of 22px, padding `0 8px`, border radius `4px`, font size `11px`, font weight `500`.
- **Status Beacon:** A 6px circular dot embedded before label text. Pulses with a `box-shadow: 0 0 8px currentColor` when real-time evaluation or audio streaming is live.
- **Branch Badges:**
  - CSE: Background `rgba(139, 92, 246, 0.1)`, text `#A78BFA`, border `1px solid rgba(139, 92, 246, 0.25)`.
  - ECE: Background `rgba(16, 185, 129, 0.1)`, text `#34D399`, border `1px solid rgba(16, 185, 129, 0.25)`.
  - EE: Background `rgba(245, 158, 11, 0.1)`, text `#FBBF24`, border `1px solid rgba(245, 158, 11, 0.25)`.
  - ME: Background `rgba(244, 63, 94, 0.1)`, text `#FB7185`, border `1px solid rgba(244, 63, 94, 0.25)`.

### Code Editor & Telemetry Panels (Monaco integration)
- Background `#0B0C10` or `#12141C`, separated by 1px vertical borders `#1D212C`.
- Header bar: Height 36px, background `#0E1017`, containing active tab, run button, and execution state dot.
- Output Console: Monospaced terminal container with log levels colored respectively: system info (`#06B6D4`), execution errors (`#EF4444`), output values (`#F8FAFC`).

### Input Fields
- Background `#12141C`, border `1px solid #262A38`, text `#F8FAFC`, placeholder `#475569`.
- Height: 36px (regular), 32px (compact/code parameters).
- Focus state: Border `#8B5CF6`, outline none, inner shadow `0 0 0 1px #8B5CF6`.

### Cards & Telemetry Widgets
- Background `#181B26`, border `1px solid #262A38`, corner radius `8px`, padding `16px`.
- Metric Displays: Monospaced numerical readouts paired with uppercase `11px` Geist labels. Interactive cards elevate slightly on hover with `#3B4155` border tinting.
